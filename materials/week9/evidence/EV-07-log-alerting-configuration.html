Logging and Alerting Configuration

Settings export from the central log server on ng-backup01, plus the alert rule list. Provided by James Chen on 10 September 2026.

Fictional scenario for training. All names, companies, and addresses are made up.

In short

Northgate collects some logs in one place (a central syslog server) and has a few alert rules that send email. This page shows which systems send logs, how long logs are kept, and which alert rules are turned on. Compare it with what happened in April 2026: which of the attacker's actions would these rules catch today?

There is no written schedule for reviewing logs. The alert history shows who acknowledged (answered) each alert and when.

What to do with this
