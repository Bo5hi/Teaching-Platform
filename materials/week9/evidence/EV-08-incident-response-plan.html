1. Purpose

This plan helps Northgate find, stop, and recover from security incidents quickly. It was written after incident INC-2026-001 (April 2026) so that next time we are ready.

2. What is an incident?

Any event that may harm Northgate's data, systems, or money. Examples: a stolen password, a virus or ransomware, a lost laptop with company data, an unknown account on a server, or a fake bank-change request from a "vendor".

5. Steps

  1. Prepare: keep this plan and the contact list up to date. Keep admin passwords in the IT password vault.
  2. Detect and analyze: check alerts (see the log server). Decide the severity level. Start an incident log (time, what happened, who did what).
  3. Contain: disconnect affected computers from the network. Disable affected accounts. Block bad IP addresses at the firewall.
  4. Eradicate: remove unknown accounts, scheduled tasks, and software. Reset passwords.
  5. Recover: restore from backup if needed. Watch the system closely for 2 weeks.
  6. Lessons learned: meet within 2 weeks. Write down what went well, what did not, and actions with owners.
