How to read a scan

Host
One device on the network, such as a server, a computer, or a printer. Each host has an IP address (for example 10.20.1.10) and often a name (for example ng-web01).
Port
A numbered "door" on a host. Programs listen on ports for connections. A port number has a type: tcp or udp. For example, 443/tcp is port 443 using TCP.
State
open: something answered. closed: the host answered "nothing here". filtered: a firewall blocked the check, so there was no answer. open|filtered: the scanner cannot tell which.
Service
The program that answers on a port. Common examples: ssh (22, remote login), http (80, web), https (443, secure web), ftp (21, file transfer), microsoft-ds (445, Windows file sharing), snmp (161, device management), mysql (3306, database).
Version
What the scanner guesses the program is. Words like "old release" mean the program is out of date.
Lines starting with |
Extra details from Nmap's checks, for example a certificate's dates or a web page title.
Severity
How serious a weakness is: Critical, High, Medium, or Low. Critical and High should be fixed first.
CVSS
Common Vulnerability Scoring System. A score from 0.0 to 10.0 that measures how serious a weakness is. Higher is worse. 9.0 or more is Critical.
Plugin ID
The number the scanner uses for one type of check. Use it to point to a finding, for example "plugin 900237".

Tips

  • Most workstations show the same three Windows ports (135, 139, 445). That is normal. Look for the hosts that are different.
  • Check every host name and IP address against EV-03. A host that answers the scan but is not in the inventory is a finding.
  • A scan shows what is there today. It does not show why. Ask James about anything that surprises you.

What to do with this

  1. Read SCAN-03-nessus-summary.html first, then look at SCAN-01 and SCAN-02 for the details.
  2. Cite scan evidence by ID in your evidence file and control review, the same way you cite EV items, for example "SCAN-02, host 10.20.1.10, port 443/tcp".
  3. Everything here is fictional practice data. Never scan a real network without written permission.
